RGB + 3 potenciómetros sobre Arduino Uno

Cada potenciómetro controla un canal de color: su posición (0–1023) se traduce a intensidad PWM (0–255) para ese canal del LED RGB, produciendo toda la gama de colores.

Pasos de conexión

  1. En cada potenciómetro: pata izquierda a 5V, pata derecha a GND, pata central (wiper) a su entrada analógica (A0, A1 o A2).
  2. Cada pata de color del LED (R, G, B) a su propia resistencia de 220Ω en serie.
  3. El otro extremo de cada resistencia al pin PWM correspondiente: D9 (R), D10 (G), D11 (B).
  4. La pata común del LED (cátodo) a GND.

El Uno solo genera PWM real (analogWrite) en los pines marcados ~: 3, 5, 6, 9, 10, 11. Los pines A0–A5 son solo de lectura (analogRead) — por eso los potenciómetros van ahí y el LED va en los PWM.

Código de referencia

src/uno/main.cpp 
const int POT_R_PIN = A0;
const int POT_G_PIN = A1;
const int POT_B_PIN = A2;

const int LED_R_PIN = 9;
const int LED_G_PIN = 10;
const int LED_B_PIN = 11;

void setup() {
  pinMode(LED_R_PIN, OUTPUT);
  pinMode(LED_G_PIN, OUTPUT);
  pinMode(LED_B_PIN, OUTPUT);
}

void loop() {
  int red = analogRead(POT_R_PIN) / 4;
  int green = analogRead(POT_G_PIN) / 4;
  int blue = analogRead(POT_B_PIN) / 4;

  analogWrite(LED_R_PIN, red);
  analogWrite(LED_G_PIN, green);
  analogWrite(LED_B_PIN, blue);
}
