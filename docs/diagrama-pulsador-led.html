Pulsador + LED sobre Arduino Uno

El LED en D8 se enciende mientras el pulsador en D2 está presionado y se apaga al soltarlo, leído directamente en cada ciclo de loop(), sin delay().

Pasos de conexión

  1. Une una pata del pulsador al pin D2 y la otra a GND.
  2. Conecta el ánodo del LED a un extremo de la resistencia de 220Ω.
  3. Conecta el otro extremo de la resistencia al pin D8.
  4. Conecta el cátodo del LED a GND.

El pin D2 se declara INPUT_PULLUP: el pull-up interno mantiene el pin en HIGH cuando el botón está suelto, así que no necesitas una resistencia externa en esa rama — solo el pulsador entre D2 y GND.

Código de referencia

src/uno/main.cpp 
const int BUTTON_PIN = 2;
const int LED_PIN = 8;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  bool pressed = digitalRead(BUTTON_PIN) == LOW;
  digitalWrite(LED_PIN, pressed ? HIGH : LOW);
}
